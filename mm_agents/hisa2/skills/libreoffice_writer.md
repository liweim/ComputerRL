# Skill: LibreOffice Writer

- Modify existing files in place with the appropriate library rather than creating new files unless explicitly instructed.
- Close the target file in the GUI before script-based modifications to avoid permission errors.
- Prefer complete overwrites of target content blocks instead of appending when deterministic output matters.
- Preserve existing headers, titles, styles, and structure unless the task explicitly asks to change them.
- Maintain fonts, colors, and formatting during script-based edits.
- Writer does not support real-time collaborative editing like Google Docs.
