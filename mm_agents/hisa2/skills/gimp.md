# Skill: GIMP

- GIMP is for raster image editing. Video, audio, and vector conversion tasks are outside its capabilities.
- For precise bulk operations, prefer scripting such as Python or Pillow over repetitive GUI edits.
- For complex visual effects and tool-specific behavior, prefer the GUI so the exact effect matches the application.
- GIMP supports RGB, Grayscale, and Indexed color modes, not CMYK.
- GIMP can rasterize imported SVG files but cannot export vector formats like SVG.
- GIMP has no built-in browser or network download support; remote images must be downloaded first.
- RAW support is limited and may require plugins or external converters.
- Higher resolution while keeping or shrinking file size is fundamentally constrained.
- GIMP has no built-in GUI for batch processing many files; use command-line tools or scripts instead.
- Theme options are limited to Dark, Light, and System.
